# Car Dealership Web Application

[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?style=for-the-badge&logo=vercel)](https://vercel.com/devnoories-projects/v0-car-dealership-page)

## Overview

This repository contains the source code for a **Car Dealership Web Application**.  
The project demonstrates a modern, responsive web interface for browsing cars, built using **Next.js, React, and Tailwind CSS**.

The application allows users to:
- Browse available cars with images and details.
- Filter cars by model, year, or price.
- View car details on a clean, responsive layout.

---

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS  
- **Deployment:** Vercel  
- **Version Control:** Git & GitHub
